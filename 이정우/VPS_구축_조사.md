# COLMAP + HLoc 기반 자체 VPS 구축

## 개요

스마트폰으로 실내 공간을 촬영해 기준 지도를 만들고, 사용자가 주변을 비추면 현재 위치와 방향을 찾는 방식이다.

- COLMAP: 사진으로 3D 공간과 카메라 위치 생성
- HLoc: 사용자 사진과 기준 지도를 비교해 현재 위치 추정
- ARCore 또는 WebXR: 위치 인식 이후 이동 추적
- A* 알고리즘: 출구, 엘리베이터 등 목적지까지 경로 계산

## 전체 흐름

```
[지도 구축]

스마트폰으로 실내 촬영
→ 영상에서 이미지 추출
→ COLMAP으로 3D 지도 생성
→ HLoc용 이미지 특징 데이터 생성
→ 출구, 엘리베이터, 복도 정보 등록
```

```
[사용자 위치 인식]

사용자가 주변 촬영
→ 이미지 서버 전송
→ 비슷한 기준 이미지 검색
→ 특징점 비교
→ 현재 위치와 방향 계산
→ 지도에 현재 위치 표시
```

## 구축 단계

### 1. 실내 촬영

- 복도나 실내 공간을 스마트폰으로 촬영
- 같은 공간을 여러 방향에서 촬영
- 시작점에서 끝점, 끝점에서 시작점으로 왕복 촬영
- 표지판, 문, 기둥 등이 잘 보이도록 촬영
- 흔들리거나 흐린 장면은 최대한 줄임

영상으로 촬영한 뒤 일정 간격으로 이미지를 추출해 사용할 수 있다.

### 2. 3D 지도 생성

촬영한 이미지를 COLMAP에 넣어 다음 데이터를 생성한다.

- 사진별 카메라 위치와 방향
- 공간의 3D 특징점
- Sparse Point Cloud
- 필요하면 Dense Point Cloud와 3D Mesh

위치 인식에는 화려한 3D Mesh보다 Sparse Map과 특징점 정보가 더 중요하다.

### 3. 위치 인식 서버 구축

사용자 사진을 서버로 전송하면 HLoc가 다음 과정을 수행한다.

```
사용자 이미지
→ 비슷한 기준 이미지 검색
→ 특징점 추출
→ 기준 이미지와 특징점 매칭
→ 3D 지도와 사용자 이미지 연결
→ 현재 위치와 방향 계산
```

서버에서는 대략 다음 데이터를 반환한다.

```
{
  "success": true,
  "position": {
    "x": 7.4,
    "y": 1.5,
    "z": -3.1
  },
  "rotation": {
    "x": 0.01,
    "y": 0.72,
    "z": -0.02,
    "w": 0.69
  }
}
```

### 4. 지도와 길찾기 데이터 구축

COLMAP이 출구나 엘리베이터를 자동으로 구분해주지는 않는다.

따라서 다음 정보는 직접 추가해야 한다.

- 출구 위치
- 엘리베이터 위치
- 화장실 위치
- 복도와 교차점
- 이동 가능한 경로
- 계단, 엘리베이터 여부

이 정보를 노드와 간선 형태로 저장하고 A* 알고리즘으로 최단 경로를 계산한다.

### 5. 웹 서비스 연결

```
Vue 웹
→ 사용자 카메라 실행
→ 이미지 캡처
→ FastAPI 위치 인식 서버 전송
→ 현재 위치 반환
→ 2D 지도에 위치와 경로 표시
```

처음에는 사용자가 현재 위치 찾기 버튼을 눌렀을 때만 인식하도록 구현하는 것이 가장 간단하다.

이후에는 ARCore나 WebXR을 연결해 위치 인식 이후의 움직임을 추적할 수 있다.

## 장점

- 외부 VPS 서비스에 의존하지 않음
- 지도와 위치 데이터를 직접 관리할 수 있음
- 일반 스마트폰으로 공간 촬영 가능
- 출구, 엘리베이터, 경로 정보를 자유롭게 추가 가능
- 컴퓨터 비전과 AI 기술을 프로젝트 핵심 기능으로 보여줄 수 있음
- API 호출 비용 부담이 적음

## 단점

- COLMAP만으로 전체 VPS가 완성되는 것은 아님
- HLoc 서버와 웹 API를 별도로 구축해야 함
- 흰 벽이나 비슷한 복도가 반복되면 위치 인식이 어려움
- 조명이나 시설 배치가 크게 바뀌면 정확도가 떨어질 수 있음
- GPU가 없으면 위치 인식 속도가 느릴 수 있음
- 실제 거리 단위로 맞추기 위한 좌표 보정이 필요함
- 실시간 영상 전체를 서버에서 처리하기에는 부담이 큼

## MVP 권장 범위

```
공간
- 복도 한 구역
- 한 개 층
- 약 20~50m

촬영 데이터
- 이미지 약 200~500장

목적지
- 출구
- 엘리베이터
- 화장실 등 3~5개

핵심 기능
- 사용자 사진 한 장으로 현재 위치 찾기
- 2D 지도에 현재 위치 표시
- 목적지까지 최단 경로 표시
```

## 개발 우선순위

1. 스마트폰으로 공간 촬영
2. COLMAP으로 Sparse Map 생성
3. HLoc로 테스트 이미지 위치 인식
4. 2D 지도에 현재 위치 표시
5. 출구와 엘리베이터 POI 등록
6. A* 길찾기 구현
7. 시간이 남으면 AR 안내 추가

## 결론

COLMAP과 HLoc를 사용하면 스마트폰으로 촬영한 실내 공간을 기반으로 자체 VPS를 구축할 수 있다.

다만 처음부터 3D 지도와 실시간 AR 길찾기까지 모두 구현하기보다는 다음 흐름을 먼저 완성하는 것이 현실적이다.

```
실내 촬영
→ COLMAP 지도 생성
→ HLoc 위치 인식
→ 2D 지도에 현재 위치 표시
→ 목적지까지 길찾기
```
