# 지하철역 실내 VPS 구축을 위한 LiDAR 조사 방법

## 1. 핵심 결론

LiDAR는 일반 사용자의 실시간 위치를 추적하는 장비라기보다, **지하철역 내부의 기준 3D 지도를 처음 구축하는 조사 장비**로 사용하는 것이 적절하다.

```text
[사전 지도 구축]

LiDAR + RGB 카메라 + IMU
→ 역사 내부 3D 구조 조사
→ 포인트클라우드 및 기준 이미지 구축
→ Visual Positioning System용 지도 생성


[실제 서비스 이용]

일반 사용자 스마트폰 카메라 + IMU
→ 현재 영상을 기준 지도와 비교
→ 현재 위치와 방향 추정
→ AR 또는 2D 길안내 제공
```

즉, 실제 서비스 사용자는 LiDAR가 없는 갤럭시 스마트폰으로도 이용할 수 있다.

---

## 2. LiDAR가 필요한 이유

일반적인 실내 평면도만으로는 사용자가 복도의 어느 위치에 있는지, 어느 방향을 보고 있는지 판단하기 어렵다.

LiDAR를 이용하면 다음 정보를 확보할 수 있다.

* 벽, 바닥, 천장, 기둥의 3D 위치
* 복도 폭과 길이
* 계단과 에스컬레이터의 위치
* 층간 높이 차이
* 통행 가능한 공간
* 카메라 기준 이미지의 정확한 촬영 위치
* Visual Localization 성능 평가용 기준 좌표

하지만 LiDAR 데이터만으로는 카메라 기반 VPS를 완성할 수 없다.

사용자는 RGB 카메라 영상을 보내기 때문에, 조사 단계에서도 다음 데이터가 함께 필요하다.

```text
LiDAR
→ 정확한 공간 구조

RGB 카메라
→ 간판, 모서리, 조명, 타일 등 시각적 특징

IMU
→ 조사 장비의 이동과 회전

센서 캘리브레이션
→ 카메라 이미지와 LiDAR 좌표 연결
```

---

## 3. 필요한 장비

### 필수 구성

* LiDAR 센서 또는 LiDAR 탑재 기기
* RGB 카메라
* 가속도계 및 자이로스코프가 포함된 IMU
* 센서 데이터를 저장할 장치
* SLAM 및 포인트클라우드 처리 소프트웨어

직접 센서를 조립할 수도 있지만, 센서 시간 동기화와 좌표계 보정이 어렵기 때문에 통합 장비를 사용하는 것이 편하다.

## 4. 장비 선택지

### 4.1 프로젝트 MVP: LiDAR 탑재 iPhone 또는 iPad Pro

가장 현실적인 학생 프로젝트용 방법이다.

#### 필요한 것

* LiDAR가 탑재된 iPhone Pro 또는 iPad Pro
* Polycam, SiteScape, Dot3D 등의 스캔 앱
* RGB 영상 촬영
* 포인트클라우드 후처리용 노트북

#### 활용 방법

```text
지하철역 일부 구간 스캔
→ PLY, LAS, OBJ 등의 형식으로 내보내기
→ 벽과 통로 구조 확인
→ 층별 지도와 경로 그래프 생성
→ RGB 기준 이미지와 결합
```

#### 장점

* 전문 장비보다 저렴하다.
* 대여하거나 지인 기기를 빌리기 쉽다.
* 앱을 통해 바로 포인트클라우드를 생성할 수 있다.
* 복도 50~100m 정도의 MVP 조사에 적합하다.

#### 한계

* 장거리 복도에서 오차가 누적될 수 있다.
* 여러 층을 하나의 스캔으로 연결하기 어렵다.
* 전문 측량 수준의 정밀도는 기대하기 어렵다.
* 사람이 많거나 유리·거울이 많은 공간에서 결과가 흔들릴 수 있다.

---

### 4.2 중간 단계: Leica BLK2GO

BLK2GO는 들고 걸어 다니며 공간을 조사하는 이동형 LiDAR 장비다.

일반적으로 다음 센서가 통합되어 있다.

* 회전형 LiDAR
* RGB 카메라
* IMU
* SLAM 처리 시스템

#### 장점

* 긴 복도와 대형 실내 공간을 빠르게 조사할 수 있다.
* LiDAR, 카메라, IMU가 이미 보정되어 있다.
* 스마트폰 LiDAR보다 안정적인 포인트클라우드를 생성할 수 있다.
* 지하철역 대합실과 환승통로 조사에 적합하다.

#### 단점

* 구매 비용이 높다.
* 전용 소프트웨어와 후처리 과정이 필요하다.
* 학생 프로젝트에서는 구매보다 대여 또는 업체 의뢰가 현실적이다.

---

### 4.3 대규모 조사: NavVis VLX

NavVis VLX는 사람이 착용하거나 들고 걸어 다니는 전문 실내 매핑 장비다.

다음과 같은 대형 공간 조사에 적합하다.

```text
대합실
→ 환승통로
→ 계단
→ 승강장
→ 다른 층
→ 다시 출발 지점
```

#### 장점

* 대형 역사 전체 조사에 적합하다.
* 여러 개의 LiDAR와 카메라를 사용한다.
* 복잡한 실내 공간에서도 비교적 안정적인 SLAM 결과를 얻을 수 있다.
* 제어점과 기준 좌표를 이용한 정밀 보정이 가능하다.

#### 단점

* 장비와 소프트웨어 비용이 매우 높다.
* 학생 프로젝트 규모에는 과도하다.
* 전문 업체 또는 연구기관과의 협업이 필요하다.

### 4.4 고정형 LiDAR: Leica BLK360

삼각대에 LiDAR를 세워 한 지점씩 스캔하는 방식이다.

```text
스캔 지점 A
→ 스캔 지점 B
→ 스캔 지점 C
→ 서로 겹치는 영역을 기준으로 정합
```

#### 장점

* 정지 상태에서 촬영하므로 정확도가 높다.
* 특정 대합실이나 넓은 공간을 정밀하게 조사하기 좋다.
* 건축 도면이나 정밀 3D 모델 제작에 적합하다.

#### 단점

* 스캔 지점마다 삼각대를 옮겨야 한다.
* 긴 환승통로나 승강장 조사에 시간이 많이 걸린다.
* 이동형 장비보다 조사 속도가 느리다.

## 5. Galaxy Z Flip5로 가능한 것

Galaxy Z Flip5에는 물리적인 LiDAR 센서가 없다.

다만 ARCore와 카메라, IMU를 이용해 다음 기능은 구현할 수 있다.

### 가능한 기능

* RGB 영상 수집
* ARCore 기반 VIO
* 스마트폰 이동 경로 추적
* 평면 탐지
* 대략적인 깊이맵 생성
* VPS 사용자 단말 테스트
* AR 화살표 렌더링

### 어려운 기능

* 전문 LiDAR 수준의 포인트클라우드 구축
* 여러 층으로 구성된 대형 역사 정밀 조사
* 수 cm 수준의 기준 지도 제작
* 역 전체의 안정적인 3D 측량

따라서 Z Flip5는 다음 용도로 사용하는 것이 적절하다.

```text
Z Flip5
→ 실제 사용자 단말
→ RGB 데이터 수집
→ ARCore VIO 테스트
→ VPS 클라이언트 구현

LiDAR 탑재 기기
→ 기준 지도 제작
→ 포인트클라우드 생성
```

## 6. 권장 조사 범위

처음부터 서울역이나 코엑스 전체를 조사하는 것은 프로젝트 범위가 지나치게 커진다.

MVP에서는 다음 정도로 제한하는 것이 좋다.

```text
개찰구 1개
→ 복도 교차점 2~3개
→ 화장실 또는 엘리베이터
→ 특정 승강장 입구
```

권장 길이는 약 50~150m다.

### 예시

```text
6번 출구
→ 개찰구
→ 환승통로
→ 엘리베이터
→ 2호선 승강장 입구
```

## 7. 실제 조사 방법

### 7.1 사전 준비

조사 전에 다음 항목을 정리한다.

* 조사 대상 역과 구간
* 출발 지점과 목적지
* 조사할 층
* 계단, 엘리베이터, 에스컬레이터 위치
* 혼잡 시간대
* 촬영 및 장비 사용 허가 여부
* 개인정보가 촬영되지 않도록 하는 방법

---

### 7.2 이동 경로 설계

SLAM의 누적 오차를 줄이려면 출발 지점과 종료 지점이 겹치도록 조사해야 한다.

```text
출발점 A
→ 교차점 B
→ 목적지 C
→ 교차점 B 재방문
→ 출발점 A 복귀
```

이처럼 같은 장소를 다시 방문하는 것을 `Loop Closure`라고 한다.

Loop Closure가 있으면 SLAM이 출발 위치와 도착 위치가 같은 장소라는 것을 인식해 누적 오차를 보정할 수 있다.

---

### 7.3 조사 시 이동 방법

* 일정하고 느린 속도로 이동한다.
* 장비를 빠르게 흔들지 않는다.
* 교차로에서는 천천히 회전한다.
* 동일한 장소를 여러 방향에서 촬영한다.
* 한 방향으로만 촬영하지 말고 정방향과 역방향으로 이동한다.
* 바닥과 천장만 보이지 않도록 벽과 안내판을 함께 촬영한다.
* 사람이 지나갈 때는 잠시 기다리거나 여러 번 촬영한다.
* 계단과 에스컬레이터는 별도 구간으로 나누는 것이 좋다.

---

### 7.4 주의해야 할 장소

다음 환경에서는 LiDAR SLAM과 Visual Localization 모두 어려워질 수 있다.

* 긴 흰색 벽
* 동일한 기둥이 반복되는 승강장
* 유리 벽
* 거울
* 움직이는 열차
* 출퇴근 시간대의 인파
* 공사 가림막
* 변경이 잦은 광고판
* 무빙워크
* 에스컬레이터
* 엘리베이터 내부

이러한 장소에서는 다음 방법을 사용할 수 있다.

```text
반복 촬영
+ 이동 속도 감소
+ 교차점 재방문
+ 고정된 안내판과 구조물 중심 촬영
+ 층간 이동 후 VPS 재인식
```

## 8. 데이터 처리 과정

LiDAR 조사 후 바로 VPS가 만들어지는 것은 아니다.

다음과 같은 후처리가 필요하다.

```text
1. LiDAR 원본 데이터 수집
2. LiDAR SLAM 수행
3. 여러 구간의 포인트클라우드 정합
4. Loop Closure를 통한 누적 오차 보정
5. 사람, 열차 등 동적 객체 제거
6. 바닥, 벽, 기둥 구조 추출
7. 층별 2D 평면도 생성
8. RGB 기준 이미지 추출
9. 각 이미지의 6DoF 카메라 포즈 생성
10. Visual Localization 데이터베이스 구축
11. 통행 가능한 경로 그래프 작성
12. VPS와 ARCore VIO 결합
```

## 9. 최종 산출물 예시

### 3D 포인트클라우드

```text
station.ply
station.pcd
station.e57
```

역사 내부 벽, 바닥, 기둥 등의 3D 좌표가 저장된다.

### 층별 실내 지도

```text
floor_B1.geojson
floor_B2.geojson
```

다음 정보를 포함한다.

* 벽
* 통로
* 계단
* 엘리베이터
* 에스컬레이터
* 출입구
* 화장실
* 주요 POI

### 경로 그래프

```json
{
  "nodes": [
    {
      "id": "N1",
      "type": "gate",
      "floor": "B1",
      "x": 10.2,
      "y": 4.8
    },
    {
      "id": "N2",
      "type": "intersection",
      "floor": "B1",
      "x": 22.1,
      "y": 8.4
    }
  ],
  "edges": [
    {
      "from": "N1",
      "to": "N2",
      "distance": 13.2,
      "accessible": true
    }
  ]
}
```

### 위치 인식용 기준 이미지

```text
reference_images/
├── B1_zone_A_001.jpg
├── B1_zone_A_002.jpg
├── B1_zone_B_001.jpg
└── B1_zone_B_002.jpg
```

### 이미지별 카메라 포즈

```text
camera_poses.txt
```

각 기준 이미지가 실제 공간의 어느 위치와 방향에서 촬영되었는지 저장한다.

```text
이미지 이름
x, y, z
roll, pitch, yaw
```

## 10. 카메라 기반 VPS와 연결하는 방법

LiDAR 지도와 RGB 기준 이미지가 만들어지면, 사용자의 스마트폰 영상으로 현재 위치를 계산한다.

```text
사용자 스마트폰 카메라
→ 현재 이미지 촬영
→ 전체 기준 이미지 중 비슷한 구역 검색
→ 로컬 특징점 추출
→ 기준 이미지 및 3D 특징점과 매칭
→ PnP + RANSAC
→ 카메라의 전역 6DoF 계산
```

### 6DoF

```text
위치
- x
- y
- z

방향
- roll
- pitch
- yaw
```

이 위치를 ARCore VIO와 결합한다.

```text
VPS
→ 지하철역 전체 좌표에서 현재 위치 확인

ARCore VIO
→ 직전 위치에서 얼마나 움직였는지 빠르게 추적

주기적인 VPS 재인식
→ VIO 누적 오차 보정
```

## 12. 프로젝트 권장 구현안

### 1단계: 데이터 수집

```text
LiDAR 탑재 iPhone 또는 iPad Pro 대여
→ 역사 일부 구간 50~100m 스캔
→ PLY 포인트클라우드 추출

Z Flip5
→ 같은 구간 RGB 영상 촬영
→ ARCore VIO 데이터 수집
```

### 2단계: 지도 구축

```text
포인트클라우드 정리
→ 벽과 바닥 구조 추출
→ 층별 실내 지도 작성
→ 경로 노드와 간선 수동 입력
```

### 3단계: Visual Localization

```text
RGB 영상에서 기준 이미지 추출
→ COLMAP으로 이미지 기반 3D 특징 지도 생성
→ hloc 또는 LightGlue로 이미지 매칭
→ pycolmap PnP로 스마트폰 위치 계산
```

### 4단계: 경로 안내

```text
현재 위치를 가장 가까운 경로 노드에 스냅
→ A*로 목적지 경로 탐색
→ 직진, 좌회전, 우회전 안내 제공
```

### 5단계: AR 적용

Visual Localization이 안정적인 구간에서만 AR 화살표를 표시한다.

```text
초기 버전
→ 2D 지도와 방향 안내

안정화 이후
→ 카메라 화면 위 AR 화살표

최종 버전
→ VPS + VIO 기반 연속 AR 길안내
```

## 13. LiDAR 없이도 가능한가

가능하다.

스마트폰 RGB 영상만으로도 COLMAP의 Structure-from-Motion을 이용해 3D 특징 지도를 만들 수 있다.

```text
스마트폰 영상
→ 프레임 추출
→ 이미지 특징점 매칭
→ 카메라 궤적 계산
→ 3D 특징 지도 생성
```

다만 LiDAR가 있으면 다음 부분에서 도움이 된다.

* 실제 공간 크기와 스케일 보정
* 긴 복도에서의 누적 오차 감소
* 층간 구조 파악
* 벽과 통로 위치 확인
* Visual Localization 결과의 정확도 평가
* 실내 평면도 생성

따라서 프로젝트에서 LiDAR는 필수라기보다 **기준 지도와 정답 데이터를 안정적으로 만드는 보조 수단**으로 보는 것이 적절하다.

## 15. 최종 결론

지하철역 실내 VPS 프로젝트에서 LiDAR는 사용자가 항상 들고 다니는 장비가 아니다.

LiDAR는 지하철역 내부의 정확한 기준 공간을 처음 구축하는 데 사용하고, 실제 서비스에서는 일반 스마트폰 카메라와 IMU로 사용자의 위치를 추정하는 구조가 가장 현실적이다.

학생 프로젝트에서는 다음 구성이 적절하다.

```text
LiDAR 탑재 iPhone 또는 iPad Pro로 소규모 공간 조사
+
Z Flip5로 RGB 영상과 ARCore 데이터 수집
+
COLMAP, hloc, LightGlue, pycolmap으로 Visual Localization
+
A* 경로 탐색
+
안정적인 구간에만 AR 길안내 적용
```

처음부터 지하철역 전체와 완전한 AR 내비게이션을 목표로 하기보다 다음 순서로 개발하는 것이 좋다.

```text
현재 층과 구역 인식
→ 경로 노드 스냅
→ 텍스트 및 2D 방향 안내
→ Visual Localization 정확도 개선
→ ARCore VIO 결합
→ AR 화살표 적용
```

핵심은 LiDAR 자체가 아니라 다음 세 가지다.

1. 정확한 기준 공간 지도
2. 스마트폰 카메라 기반 전역 위치 인식
3. VIO를 이용한 연속적인 이동 추적
